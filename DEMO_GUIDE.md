## Сценарий на 5 минут

1. Войдите под Алексом. В ленте представлены AI Case Trainer, CampusMatch
   и вакансия FinTrack. Проверьте фильтры «Стартапы» и «Вакансии».
2. Над лентой откройте «Рекомендуем вам»: CampusMatch подходит Алексу
   по Python, FastAPI и PostgreSQL. Это **Smart Matching** — студент → проекты.
3. В «Кабинет → Мои отклики» у Алекса уже есть принятый отклик на CampusMatch.
4. Выйдите и войдите под Полиной. В «Кабинет → Входящие» у CampusMatch
   видны Алекс, статус «Принят», совпавшие навыки и объяснение.
   Это **Reverse Matching** — помощь автору в рассмотрении кандидатов.
5. В «Мои публикации» у CampusMatch откройте блок «Компетенции команды»:
   Python, FastAPI и PostgreSQL покрыты принятым участником; отдельно
   перечислены ещё не покрытые навыки. Это **Team Readiness**.
6. В «Мои отклики» Полины отклик на FinTrack находится «На рассмотрении».
   Под Алексом он виден во «Входящих». Дизайнерские навыки Полины не совпадают
   с backend-требованиями вакансии: нейтральное сообщение здесь ожидаемо.
   У FinTrack нет принятых участников, поэтому команда показана как ещё не сформированная.

Для просмотра не нужно изменять статусы, профили или публикации. Проверки
создания, изменения и удаления выполняйте только на собственных временных
записях. Основной сценарий включает создание стартапа/вакансии, отклики,
ручное принятие/отклонение, закрытие и повторное открытие публикаций.

## Как работает подбор

Все три механизма используют общий словарь навыков и русско-английских
синонимов: например, «пайтон» → Python, «бэкенд» → Backend. Сравниваются
целые слова и фразы, а не случайные подстроки. Это правила, **не ML или LLM**;
внешние AI API не используются. Нет искусственных процентов или рейтингов.

Словарь ограничен: опыт, отрицания, опечатки и неизвестные компетенции
не оцениваются. Team Readiness учитывает только принятые отклики, без автора.
Полное покрытие распознанных навыков не гарантирует готовность команды.
Решения о принятии всегда остаются за автором; сведения о кандидатах и команде
доступны только автору соответствующей публикации.

## Проверки и локальный запуск

23 октября 2026 года: 78 backend-тестов прошли, frontend lint и build успешны.
Production-функциональность соответствует коммиту `529b233`.

```bash
git clone https://github.com/MrMrMops/business-club-ai-native.git
cd business-club-ai-native
docker compose up --build
```

Локально: сайт — http://localhost:5173, Swagger — http://localhost:8000/docs.
Для заполнения **только локальной** базы выполните:

```bash
docker compose exec backend python -m app.db.seed
```

Не запускайте seed против production. Подробности архитектуры, API,
тестирования и ограничений находятся в [README](README.md).
